# NeuroGrid Presentation

Privacy-preserving Smart Grid Intelligence — final presentation slides built with Vite + React.

Live site: https://faodubush.github.io/NeuroGrid-Final-Presentation/

Quick commands
- Install dependencies:

```bash
npm install
```

- Run dev server:

```bash
npm run dev
```

- Build production bundle:

```bash
npm run build
```

- Preview the production build locally:

```bash
npm run preview -- --port 5173
```
